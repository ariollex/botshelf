# Вклад в BotShelf

Спасибо за интерес к проекту. Перед pull request создайте отдельную ветку, опишите пользовательскую задачу и приложите проверяемый сценарий.

## Локальная проверка

```bash
go test ./...
go vet ./...
node --check cmd/server/web/app.js
```

Для просмотра интерфейса используйте `compose.local.yaml` и инструкцию из [README.md](README.md#локальный-просмотр).

## Правила данных

- Не добавляйте вымышленных ботов, ссылки или результаты модерации как реальные.
- Не коммитьте `MAX_BOT_TOKEN`, строки подключения к production-базе, `.env` и контакты пользователей.
- Сохраняйте правило: непроверенная заявка не должна попадать в публичный поиск.
